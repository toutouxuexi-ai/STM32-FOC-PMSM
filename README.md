# 基于STM32的PMSM永磁同步电机FOC矢量控制系统

## 项目简介
基于STM32主控实现永磁同步电机（PMSM）磁场定向控制（Field Oriented Control, FOC），采用增量式编码器作为位置/速度反馈，完成电流环、速度环双闭环控制，并针对硬阶跃启动超调问题完成工程化优化。

## 硬件平台
- 主控：STM32系列MCU
- 电机：永磁同步电机（PMSM），4对极
- 位置反馈：增量式编码器，硬件四倍频计数
- 调制方式：SVPWM空间矢量调制（Space Vector Pulse Width Modulation）

## 核心性能指标
| 工况 | 实测指标 |
|------|----------|
| 0→3000rpm 空载阶跃响应 | 上升时间约40ms，超调量6.5%，稳定时间约150ms |
| 500rpm 低速空载稳态 | 稳态转速波动 ±6rpm，稳态静差 < 0.5% |
| 3000rpm 中高速空载稳态 | 稳态相对误差 < 0.5% |

## 工程优化记录
初始硬阶跃指令启动时超调接近40%，分析核心原因为大误差下积分饱和、指令突变冲击。最终采用工程化方案优化：
1.  **积分分离PI**：大误差阶段暂停积分，仅比例环节作用，避免积分饱和；小误差阶段投入积分消除静差
2.  **速度指令步长斜坡限制**：限制每个控制周期指令的最大变化量，从给定输入端缓解启动冲击
3.  速度反馈采用一阶低通滤波（α=0.4），兼顾编码器测速噪声抑制和控制环相位滞后，平衡稳态精度与动态响应

优化后阶跃超调降至6.5%，同时保持快速响应能力。

## 功能特性
- Clarke / Park 坐标变换、反Park变换
- SVPWM空间矢量调制
- 增量编码器四倍频位置计数、M法测速
- 速度反馈一阶低通滤波
- 带积分限幅、积分分离的PI控制器
- 速度指令斜坡步长限制
- 电流环、速度环双闭环串级控制
